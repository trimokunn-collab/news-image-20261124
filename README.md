# The Day in One Page — Tuesday 24 November 2026

A one-page broadsheet PNG summing up 24 November 2026 world news from 30 verified stories: the COP31 collapse fallout leads, with Russia's reported nuclear weapon in space and the Asian markets leap below it, then the rest of the day in six sections — World &amp; Conflict, Politics, Markets &amp; Business, Technology, Sport, and Science &amp; Life. Every story was checked against its own article's date line for Tuesday 24 November 2026.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

That copies `entry.png` into `out/` as `entry.png`.

## Files

- `page.html` — the broadsheet page (1024&times;1024, inline CSS only, no network) the PNG is rendered from.
- `entry.png` — the finished one-page broadsheet.
- `main.ts` — copies `entry.png` into the output directory.
